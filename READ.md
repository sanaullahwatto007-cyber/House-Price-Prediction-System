# House Price Prediction System

A Machine Learning based House Price Prediction System built using Python and Scikit-learn.

## Project Overview

This project predicts house prices based on different property features using Machine Learning regression algorithms.

## Features

- House price prediction
- Multiple Machine Learning models
- Model performance comparison
- Streamlit web application
- Deployed online

## Machine Learning Models

The following regression models were tested:

- Linear Regression
- Support Vector Regression (SVR)
- Gradient Boosting
- Random Forest
- Decision Tree
- KNN

## Best Model

Linear Regression achieved the best R² score among the tested models.

R² Score: 0.998426

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Joblib
